The default bottom wash now uses charcoal `#24242a` through an RGB tuple, retaining its upward direction, 3 px primary cells and 0.65 paint opacity. The upstream palette remains unchanged; `PixelColor` accepts project-specific RGB tuples in addition to its existing names and hue values.

The hero wrapper paints a second version with 4 px cells. Two static layers move upward by 16 px and crossfade on a 12-second CSS loop, offset by six seconds. Each layer resets its position only at zero opacity; a 12 px overscan prevents exposed edges. Only transform and opacity animate. DitherGradient still paints only at mount, prop or size changes, without a video-sampling or canvas animation loop. The other review presets remain static.

Intersection observers pause the loop when the hero is offscreen or the foreground sheet covers it, and visibility changes pause it in hidden tabs. Both observers and event listeners are cleaned up on unmount. Reduced motion renders the single dark primary pattern without movement or crossfade. The existing forced-colour fallback still hides the decorative overlay.
