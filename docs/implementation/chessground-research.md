## Is it open source?

Yes. Chessground is the chessboard UI developed for lichess.org. Its exact declared license is **GPL-3.0-or-later**. The README explicitly says a website's combined work may be distributed only under GPL and that its source must be released to users. The license includes copyright/license notice and corresponding-source conditions. Browser JavaScript distribution therefore needs review of the combined frontend's licensing and source delivery, rather than treating Chessground as an MIT replacement. This finding concerns the board package, not every Lichess service or its artwork. Sources: [README](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/README.md#license), [package manifest](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/package.json), [GPL text](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/LICENSE).

## Requested interactions

- Piece animation is configurable through `animation.enabled` and `animation.duration`. The default is 200 ms. The implementation uses `requestAnimationFrame` and easing for movement and fading. Sources: [configuration](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/config.ts), [defaults](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/state.ts), [animation](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/anim.ts).
- Drag starts by resolving the pointer's coordinates to a board square and finding that square's piece. It does not require hitting the painted piece shape. Drag updates also use `requestAnimationFrame`. Sources: [`start` and `processDrag`](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/drag.ts), [piece CSS with `pointer-events: none`](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/assets/chessground.base.css).
- Legal destination indicators use `movable.dests` and `movable.showDests`. Last-move highlights use `lastMove: [from, to]` and `highlight.lastMove`. The package supplies CSS examples for destination dots, capture rings and last-move squares. Sources: [configuration](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/config.ts), [board styling](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/assets/chessground.brown.css).

Chessground also supports click moves, touch input, premoves, editor piece drops, orientation changes and drawing arrows/circles. It explicitly contains no chess rules. An integration must supply legal destinations, validate moves and retain the existing rules/controller for turn order, promotion, adjudication and clocks. The documented API initializes an imperative widget, updates it through `set`, and tears down handlers with `destroy`. Sources: [feature list and installation](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/README.md#features), [API](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/src/api.ts).

## Recommendation for this app

The owner accepted Chessground's license and requested using Lichess's board during this task on 2026-10-18. The app now uses the maintained npm package `@lichess-org/chessground` pinned to 10.4.2. The unscoped `chessground` npm package is deprecated and is not installed. See the [official package manifest](https://github.com/lichess-org/chessground/blob/69f3451c9d70d682d5421539f28d68a15cfda4cd/package.json) and [dependency inventory](../dependency-notices.md).

Chessground replaces the previous cm-chessboard runtime dependency. The integration supplies legal destinations from the rules adapter and submits moves through the existing fenced game controller. The owner subsequently adopted GPL-3.0-or-later for the project, including original application code, on 2026-10-18. The existing CC BY-SA standard artwork is retained, extracted into individual images with attribution and modification notices. This authorized dependency change supersedes the earlier board choice and GPL exclusion for Chessground in the original [MVP handoff](../spec/mvp-handoff.md) and [acceptance requirements](../spec/mvp-acceptance.json).
